📖 Weather API Providers

  1. Open-Meteo (Default): Completely free and open-source public API. No key or registration required!
  2. OpenWeatherMap: Sign up at openweathermap.org → profile → API keys → copy. Free: 1000 calls/day.
  3. WeatherAPI.com: Sign up at weatherapi.com → dashboard → API Key. Free: 1M calls/month.
  4. Tomorrow.io: Sign up at tomorrow.io → developer → copy key. Free: 500 calls/day.
  5. Visual Crossing: Sign up at visualcrossing.com → account → API keys. Free: 1000 calls/day.
